Host Free on GitHub Pages

Share this site live with all your school friends!

This entire app is stored in a single file (`index.html`). No complex server setup or build process required!

  1. Save this code:

    Save this HTML code on your computer as index.html.

  2. Create a GitHub Repository:

    Go to github.com, log in, click New Repository, name it (e.g. school-squad-chat), set it to Public, and click Create repository.

  3. Upload `index.html`:

    Click "uploading an existing file" link on GitHub, drag and drop your index.html file, and click Commit Changes.

  4. Turn on GitHub Pages:

    Go to Settings > Pages in your repo. Under Build and deployment / Branch, select main branch and click Save.

  5. Share with Friends!

    In 1-2 minutes, GitHub will generate a link like: https://yourusername.github.io/school-squad-chat. Send it to your school group!
